# DOM, Browser & Advanced Concepts Interview Questions (81–100)

Welcome to the **DOM, Browser & Advanced Concepts** section of the **JavaScript Interview Questions** repository.

This module covers essential browser-related APIs, Document Object Model (DOM) manipulation, event handling, browser storage, performance optimization techniques, object-oriented programming concepts, JavaScript memory management, module systems, and the latest ECMAScript features.

These concepts are commonly asked in JavaScript interviews because they demonstrate a developer's understanding of how JavaScript interacts with web browsers and how modern JavaScript applications are built.

---

## Learning Objectives

After completing this module, you will be able to:

- Understand the Document Object Model (DOM).
- Select and manipulate DOM elements.
- Handle browser events efficiently.
- Understand event bubbling, capturing, and delegation.
- Differentiate between `preventDefault()` and `stopPropagation()`.
- Work with browser storage mechanisms.
- Understand cookies.
- Improve application performance using debouncing and throttling.
- Learn memoization and currying.
- Understand prototype-based inheritance.
- Work with JavaScript classes.
- Learn JavaScript memory management and garbage collection.
- Differentiate between CommonJS and ES Modules.
- Understand the latest JavaScript language features.
